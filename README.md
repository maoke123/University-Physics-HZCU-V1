# 大学物理交互式动画库

本项目收录了大学物理课程各知识点的交互式动画演示，旨在通过可视化方式帮助学生理解抽象的物理概念和原理。

## 项目结构

```
大学物理动画/
├── 力学/           # 力学相关动画
├── 光学/           # 光学相关动画
├── 热学/           # 热学相关动画
├── 电磁学/         # 电磁学相关动画
├── 近代物理/       # 近代物理相关动画
```

## 内容概览

### 力学
- 运动学与动力学：圆周运动、速度与加速度、单摆、机械振动、机械波
- 守恒定律：动量守恒与能量守恒、角动量守恒
- 其他：刚体定轴转动、牛顿第三定律、势能、静电平衡

### 光学
- 干涉：杨氏双缝干涉、光学劈尖干涉
- 衍射：菲涅尔衍射
- 反射与成像：反射镜成的像与物体的位置
- 偏振：光的偏振

### 热学
- 分子热运动：分子碰撞与平均自由程追踪、理想气体压强公式、能量均分定理与分子自由度、麦克斯韦速率分布曲线
- 热力学：准静态过程做功、卡诺循环、基本热力学过程、气体的等容摩尔热容与微观自由度、熵的微观统计

### 电磁学
- 静电学：库伦定理、点电荷的场强、场强叠加、电偶极子、带电平面、带电球（电势）、电通量、高斯定理、静电场环路定理、静电平衡交互实验
- 磁学：磁介质中的安培环路定理、磁滞回线、磁畴
- 电磁学：位移电流、电磁波、电磁波谱

### 近代物理
- 量子物理：光电效应、康普顿散射、氢原子、黑体辐射
- 相对论：同时的相对性、迈克尔逊-莫雷实验

## 使用方法

直接在浏览器中打开对应的HTML文件即可运行动画。大多数动画支持参数调节，可以通过滑动条或按钮交互式地观察物理现象。

## 技术特点

- 基于HTML5 Canvas实现的实时渲染
- 使用MathJax渲染数学公式
- 响应式设计，适配不同屏幕尺寸
- 丰富的交互控件，便于教学演示
